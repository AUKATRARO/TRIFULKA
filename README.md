# TRIFULKA
Trifülka es una plataforma privada para conectar grupos mediante videollamadas, chat y archivos sin registros previos. Funciona de forma directa mediante P2P, integrando KriptoSafe para cifrar documentos en el navegador.Incorpora herramientas multimedia y un sistema de respaldo que reasigna la coordinación automáticamente ante cualquier desconexióN
